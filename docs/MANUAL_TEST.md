# 実機での手動確認手順

リリース前に実機（できれば Android 13 以上と、手元にあれば OPPO / motorola 端末）で確認する。
準備: 監視対象にする SNS アプリ（例: X、Instagram、YouTube など）と、誘導先にするアプリ・Web サイトを決めておく。

## 1. インストール・オンボーディング

- [ ] README の手順どおり、GitHub Releases の APK をインストールできる（提供元不明のアプリの許可、Play プロテクトの警告）
- [ ] 初回起動でオンボーディングが表示される
- [ ] 「はじめに」で目的と仕組みが説明されている。次へ進むとチェックマークが付く
- [ ] 「はじめに」の説明が「データはこの端末内にだけ保存され、外部へ送信されることはありません。新しいバージョンの確認のため、GitHub に最新のバージョン番号を問い合わせます。」になっている
- [ ] 「はじめに」の末尾、「データはこの端末内にだけ保存され…」の下に、同じ小さめの文字で免責事項（README と同じ文言）が表示される
- [ ] （Android 13 以上）「制限付き設定の許可」が表示され、ボタンでアプリ情報画面が開く。︙ →「制限付き設定を許可」ができる
- [ ] （Android 12 以下）「制限付き設定の許可」ステップが表示されない
- [ ] 「ユーザー補助を有効化」のボタンでユーザー補助の設定が開き、Memory Gate の説明文に「画面の内容は読み取りません」と表示されている
- [ ] ユーザー補助をオンにしてアプリに戻ると、チェックマークが付く（制限付き設定のステップにも付く）
- [ ] 「電池の最適化から除外」のボタンでダイアログが出て、許可して戻るとチェックマークが付く
- [ ] OPPO / motorola 端末でのみ「メーカー別の追加設定」が表示され、案内の手順が正しい。チェックボックスで完了にできる
- [ ] それ以外のメーカーでは「メーカー別の追加設定」が表示されない
- [ ] 「誘導先を登録」から誘導先を追加でき、戻ると登録済みの一覧とチェックマークが表示される。未登録でもスキップできる
- [ ] 「監視対象アプリを選択」でアプリを選択でき、チェックマークが付く。未選択でも「完了」できる
- [ ] 2 ステップ目以降で「戻る」を押すと、前のステップへ戻る。システムの戻る操作（ボタン・ジェスチャー）でも同じ
- [ ] 初回起動時、「はじめに」で「戻る」ボタンが押せ、押すとアプリが閉じる。システムの戻る操作でも同じ
- [ ] 閉じたあとにアプリを起動し直すと、再びオンボーディング（はじめに）から始まる
- [ ] 「完了」でホームに移動し、アプリを再起動してもオンボーディングは表示されない
- [ ] メニュー「オンボーディングを再表示」から開き、「はじめに」で「戻る」を押すとホーム画面に戻る。システムの戻る操作でも同じ
- [ ] ホームのユーザー補助の警告バナーから開いた場合（「ユーザー補助を有効化」ステップから始まる）も、「はじめに」まで戻ってからもう一度「戻る」でホームに戻る
- [ ] ホームのメニュー「オンボーディングを再表示」から再表示できる

## 2. 誘導先・監視対象アプリの設定

- [ ] Web の誘導先: `https://` の URL を登録できる。`ftp://`・スキームなし・空欄はエラーになる
- [ ] アプリの誘導先: アプリ選択ダイアログで検索・選択できる。監視対象アプリに設定済みのアプリは選択できず理由が表示される
- [ ] スケジュール「1日ごと」「3日ごと」「1週間ごと」「毎週〇曜日」（曜日チップ）を設定できる
- [ ] ホームの一覧にタイトル、スケジュール、最終訪問、「期限切れ」バッジ、次の期限日が表示される
- [ ] 編集画面で「未訪問に戻す」を押すと、未訪問・期限切れになる
- [ ] 削除すると確認ダイアログが出て、削除できる
- [ ] 監視対象アプリの選択画面: アプリ名順に並び、検索と「選択中のみ表示」が機能する。誘導先として登録済みのアプリは選択できず理由が表示される

## 3. 除外アプリが一覧に出ないこと

監視対象アプリの選択画面で、次のアプリが**表示されない**こと。

- [ ] Memory Gate 自身
- [ ] 既定の電話アプリ
- [ ] 既定の SMS アプリ
- [ ] ホームアプリ（ランチャー）
- [ ] キーボード（IME）アプリ（ランチャーに表示されるもの）
- [ ] LINE、設定、連絡先、Google の電話 / メッセージ、Samsung の電話 / メッセージ（インストールされていれば）
- [ ] メールアプリ（Gmail、Outlook、Yahoo!メール、Samsung メール、その他 `mailto:` を開けるアプリ）
- [ ] プリインストールのまま更新されていないシステムアプリ（時計・電卓・カメラ・ファイル管理・メーカー独自ツールなど）
- [ ] Play ストア、Google Play 開発者サービス、Google アプリ
- [ ] ストアで更新されたプリインストールアプリ（YouTube、Chrome など）は表示される
- [ ] 「システムアプリも表示」スイッチは既定でオフになっている
- [ ] スイッチをオンにすると、時計・電卓・Play ストアなどのシステムアプリが表示される
- [ ] スイッチをオンにしても、メールアプリと電話・SMS・LINE・設定などの除外アプリは表示されない
- [ ] 画面を開き直すとスイッチがオフに戻る。オンボーディングの「監視対象アプリを選択」にも同じスイッチがある
- [ ] （v0.1.0 からの更新時）メールアプリなどを監視対象に登録していた場合は、一覧に表示されてチェックを外せる
- [ ] 誘導先のアプリ選択ダイアログでは、Memory Gate 以外のアプリ（電話・メール・時計など）も表示される

## 4. ゲート表示

- [ ] 期限切れの誘導先がある状態で監視対象アプリを開くと、ゲート画面「やることがあります」が全画面で表示される
- [ ] 期限切れの誘導先が最大 5 件、未訪問 → 最終訪問が古い順に並ぶ
- [ ] 各カードにタイトル、種別アイコン（Web / アプリ）、「最終: N日前」または「未訪問」、「開く」ボタンがある
- [ ] 監視対象でないアプリを開いてもゲートは出ない
- [ ] 期限切れの誘導先がないときは、監視対象アプリを開いてもゲートは出ない
- [ ] ゲートは最近のタスク（アプリ履歴）に表示されない
- [ ] ゲート表示中に通知などから監視対象アプリを再度開いても、ゲートが二重に表示されない

## 5. ボタン押下後に当日は出ないこと

- [ ] Web の誘導先の「開く」でゲートが閉じ、Custom Tabs で URL が開く
- [ ] アプリの誘導先の「開く」でゲートが閉じ、アプリが起動する
- [ ] その後、同じ日に監視対象アプリを開いてもゲートは出ない（ホームに「今日はゲート通過済み」と表示される）
- [ ] 開いた誘導先の最終訪問が「最終: 今日」になる
- [ ] 翌日（または端末の日付を翌日に変更して）監視対象アプリを開くと、期限切れがあれば再びゲートが出る
- [ ] 誘導先のアプリをアンインストールすると、ゲートでそのカードのボタンが無効になり「アプリが見つかりません」と表示される。この場合は通過扱いにならない

## 6. 緊急退避

- [ ] ゲート最下部に控えめな「長押しで退避（3秒）」ボタンがある
- [ ] 押している間に進捗リングが進み、3 秒でホーム画面に移動してゲートが閉じる
- [ ] 途中で指を離すと進捗がリセットされ、退避しない
- [ ] 退避後に監視対象アプリを再度開くと、再びゲートが出る（通過扱いにならない・最終訪問も変わらない）

## 7. 戻るボタン

- [ ] ゲートで戻るボタン / 戻るジェスチャーを使うと、ホーム画面へ移動する（監視対象アプリには戻らない）
- [ ] その後、監視対象アプリを開くと再びゲートが出る

## 8. 再起動後もサービスが動くこと

- [ ] 端末を再起動した後、Memory Gate を開かずに監視対象アプリを開いてもゲートが出る
- [ ] 再起動後もユーザー補助の設定で Memory Gate がオンのままになっている
- [ ] しばらく（数時間〜翌日）放置した後もゲートが出る（電池の最適化・メーカー別設定の効果）
- [ ] ユーザー補助をオフにすると、ホームの上部に赤い警告バナーが表示され、タップでオンボーディングの「ユーザー補助を有効化」ステップが開く

## 9. システムナビゲーションバー

ジェスチャーナビゲーションと 3 ボタンナビゲーションの両方で確認する。

- [ ] ホーム・誘導先の編集・監視対象アプリの選択・オンボーディング・ゲートの各画面で、ナビゲーションバー（戻る・ホーム・履歴の帯）が最初は非表示になっている
- [ ] ステータスバー（画面上部の時計など）は常に表示されている
- [ ] ボタンや入力欄以外の部分（余白・見出し・説明文など）をタップするたびに、ナビゲーションバーが表示・非表示に切り替わる
- [ ] ボタン・チェックボックス・スイッチ・入力欄をタップしても、ナビゲーションバーは切り替わらない。リストのスクロールでも切り替わらない
- [ ] 画面の下端からスワイプすると、ナビゲーションバーが一時的に表示され、しばらくすると自動で隠れる
- [ ] ナビゲーションバーが表示されている状態で、オンボーディングの「戻る」「次へ／スキップ／完了」ボタンが帯に重ならず、すべて押せる
- [ ] ナビゲーションバーが表示されている状態で、ホームの「誘導先を追加」ボタン、編集画面の「保存」ボタン、ゲートの「長押しで退避（3秒）」が帯に重ならない
- [ ] ゲートの「長押しで退避（3秒）」を短くタップしても、ナビゲーションバーは切り替わらない
- [ ] 誘導先のアプリ選択ダイアログでも、ナビゲーションバーが最初は非表示で、余白のタップで切り替わる
- [ ] 他のアプリから戻ってきたとき（設定画面からオンボーディングに戻るなど）は、ナビゲーションバーが非表示に戻る
- [ ] ナビゲーションバーが非表示でも、戻るジェスチャー（画面端からのスワイプ）で前の画面に戻れる。ゲートではホームへ移動する

## 10. 新しいバージョンのお知らせ

準備: 現在より新しいバージョンの GitHub Release を公開しておく（または、古いバージョンの APK をインストールしておく）。1 時間以内に確認済みの場合は、1 時間待つか、アプリ情報の「アップデートを確認」を使う。

- [ ] ホーム画面を開くと、上部に「新しいバージョン v0.1.x が公開されています」のバナーが表示される
- [ ] ユーザー補助が無効で赤い警告バナーが出ているときは、そのすぐ下にお知らせバナーが表示される
- [ ] 「ダウンロードページを開く」で、そのバージョンの GitHub のリリースページが Custom Tabs で開く
- [ ] 「×」を押すとバナーが消え、ホームを開き直したりアプリを再起動したりしても、同じバージョンについては表示されない
- [ ] 閉じたあとに、さらに新しいバージョンが公開されると（1 時間後の確認で）再びバナーが表示される
- [ ] 最新バージョンにアップデートすると、バナーは表示されない
- [ ] 最新バージョンを使っているときは、バナーは表示されない
- [ ] 機内モード（オフライン）でホームを開いても、エラーやダイアログは表示されず、普通に使える
- [ ] オフラインから復帰しても、1 時間たつまでは問い合わせない（失敗した場合も確認日時が更新される）
- [ ] ゲート画面・オンボーディングを表示しただけでは問い合わせない（ホームを開いたときだけ）

### 10.1 アップデートを確認（手動）

- [ ] メニュー →「アプリ情報」に「アップデートを確認」ボタンがある
- [ ] ホームを開いた直後（1 時間以内に確認済み）でも、ボタンを押すとすぐに問い合わせる。問い合わせ中は「確認中…」になり、押せない
- [ ] 新しいバージョンがあるときは「新しいバージョン v0.1.x が公開されています」と「ダウンロードページを開く」が表示され、押すとリリースページが Custom Tabs で開く
- [ ] 新しいバージョンがあるときは、アプリ情報を閉じるとホームにもお知らせバナーが表示される（そのバージョンを「×」で閉じていた場合は表示されない）
- [ ] 最新のバージョンを使っているときは「最新のバージョンです」と表示される
- [ ] 機内モード（オフライン）で押すと「確認できませんでした。…」と表示され、アプリは普通に使える
- [ ] アプリ情報を閉じて開き直すと、結果の表示は消えている

## 11. スヌーズ

準備: 監視対象アプリを 2 つ（例: SNS と動画アプリ）登録し、誘導先を 2 件以上用意する（期限切れでなくてもよい）。ホームのメニュー「スヌーズ設定」でスヌーズを ON にし、間隔「1分おき」、時間帯は現在時刻を含むように設定する。通常のゲートで一度「開く」を押さずに、緊急退避で閉じた状態から始める。

### 11.1 スヌーズ設定画面

- [ ] ホームのメニューに「スヌーズ設定」があり、押すとスヌーズ設定画面が開く
- [ ] スイッチを ON にすると、間隔・時間帯の設定が表示される。OFF にすると隠れる
- [ ] スイッチの左の説明文「時間帯の間、指定の間隔で表示します」が 1 行に収まり、スイッチとの間に余白がある（幅 360dp 程度の端末・標準の文字サイズで確認する）
- [ ] 初めて開いたとき（新規インストール）は OFF で、ON にすると「30分おき」「9:00〜22:00」
- [ ] 間隔のチップ「1分おき」「5分おき」「30分おき」「1時間おき」から 1 つ選べる
- [ ] 開始・終了時刻を TimePicker で変更できる。開始＞終了で「日付をまたぎます」、開始＝終了で「24 時間ずっと」と表示される
- [ ] 変更はすぐに保存される（戻ってホームを見ると状態表示に反映されている。アプリを再起動しても残っている）
- [ ] OFF にしてから再び ON にすると、前の間隔・時間帯に戻っている

### 11.2 ホームの状態表示

- [ ] ホームの上部（サービス状態・お知らせのバナーの下）に、スヌーズの状態が 1 行で表示される（例:「スヌーズ：ON（30分おき 9:00〜22:00）」「スヌーズ：OFF」）
- [ ] 幅 360dp 程度の端末で、状態表示が 1 行に収まる
- [ ] 状態表示をタップすると、スヌーズ設定画面が開く
- [ ] スヌーズ設定やスヌーズ用ゲートの「スヌーズを止める」で変更すると、ホームの表示もすぐに変わる

### 11.3 誘導先の編集画面

- [ ] スヌーズのスイッチ・間隔・時間帯はなく、「スヌーズ用ゲートの画像（任意）」だけがある
- [ ] スヌーズが OFF のときも、画像を選べる・削除できる
- [ ] 「画像を選ぶ」で Photo Picker が開き（権限の確認は出ない）、選んだ画像が丸く表示される。「画像を削除」で消える
- [ ] 丸いプレビューでも、画像が伸び縮みせず、画像の中央が円の中央に来る（スヌーズ用ゲートと同じ見え方）

### 11.4 割り込み

- [ ] その日に通常のゲートで誘導先を開いた（gatePassedDate が今日）あと、監視対象アプリを開くとスヌーズ用ゲートが表示される
- [ ] 通常のゲートの条件を満たすとき（まだ今日ゲートを通過していない）は、通常のゲートが優先して表示される
- [ ] スヌーズ用ゲートには、誘導先のうち最後に開いてから最も時間がたっているもの（未訪問が最優先）が表示される。期限切れでない誘導先でも表示される
- [ ] 誘導先が 1 件もないときは、スヌーズ用ゲートは表示されない
- [ ] 監視対象アプリを開いたまま待つと、間隔（1 分）ごとにスヌーズ用ゲートが割り込んで表示される（定期表示）
- [ ] 監視対象アプリを開いたまま通知シェードを下ろしたり、キーボードを出したりしても、タイマーは止まらない（間隔がたつと表示される）
- [ ] 別のアプリやホーム画面に移ると、監視対象アプリ以外の上ではスヌーズ用ゲートは表示されない
- [ ] 監視対象アプリを開いたまま画面をオフにすると、オフの間は表示されない。画面を点けてロックを解除すると、間隔がたっていれば表示される
- [ ] 時間帯の終わりを過ぎると表示されなくなり、翌日に時間帯へ入ると再び表示される

### 11.5 切り替え時の即時表示

準備: スヌーズ設定の間隔を「30分おき」にする（間隔を待たずに出ることを確認するため）。

- [ ] スヌーズ用ゲートを閉じた直後でも、ホーム画面や別のアプリから監視対象アプリ（SNS）を開くと、すぐにスヌーズ用ゲートが表示される
- [ ] SNS から別の監視対象アプリ（動画アプリ）に切り替えると、すぐにスヌーズ用ゲートが表示される。動画アプリから SNS に戻ったときも同じ
- [ ] SNS を使っている間に通知シェードを下ろして戻る・キーボードを出して閉じる・Memory Gate の画面を経由して戻る、では表示されない（同じアプリに戻っただけなので切り替えではない）
- [ ] 最近のタスク（アプリの履歴）から SNS を選び直した場合も、ほかのアプリから来たのであれば表示される
- [ ] スヌーズが OFF・時間帯の外のときは、切り替えても表示されない

### 11.6 「開く」の後に堂々巡りにならないこと

準備: 間隔は「30分おき」。ブラウザ（例: Chrome）も監視対象アプリに登録し、Web サイトの誘導先がスヌーズ用ゲートに出るようにする（ほかの誘導先を一度開いておく）。

- [ ] スヌーズ用ゲートで Web サイトの誘導先を「開く」とブラウザで開く。開いたブラウザ（監視対象）ではスヌーズ用ゲートがすぐには出ない
- [ ] そのままブラウザを使っていると、前回の表示から 30 分たったところで定期表示として出る
- [ ] ブラウザを開いた後に SNS へ切り替えると、SNS では（30 分たっていなくても）すぐに表示される
- [ ] 既定のブラウザを決めていない（開くときに選択ダイアログが出る）端末では、開いた先が分からないため、ブラウザでもすぐに表示されることがある（仕様）

### 11.7 時間帯外では出ないこと

- [ ] 時間帯を現在時刻を含まない範囲（例: 現在が 15:00 なら 9:00〜10:00）にすると、監視対象アプリを開いてもスヌーズ用ゲートは出ない
- [ ] 日付をまたぐ時間帯（例: 22:00〜2:00）で、範囲内（23:00 など）では出て、範囲外（12:00 など）では出ない
- [ ] 開始＝終了（24 時間）にすると、いつでも出る
- [ ] スヌーズを OFF にすると出ない

### 11.8 スヌーズ用ゲートの表示

- [ ] 背景の画像が画面全体（ステータスバー・ナビゲーションバーの裏まで）を隙間なく覆っている
- [ ] 6:00〜18:00 は入道雲の青空、それ以外の時刻は星空の背景になる（端末の時刻を変えて確認する）
- [ ] 画面の高さの 3 分の 1 あたりに、白い縁取りの丸い画像が表示される
- [ ] 丸い画像の直径は画面の幅の 4 分の 3 程度（タブレットなど幅の広い画面では 320dp まで）
- [ ] タイトル・「開く」ボタンが丸い画像や「長押しで退避（3秒）」と重ならない（文字サイズを最大にした状態や、画面の小さい端末・横向きでも確認する。重なりそうなときは円が小さくなる）
- [ ] 縦長・横長・正方形の画像を設定しても、画像が伸び縮みせず、画像の中央が円の中央に来る（左右・上下に片寄らない）
- [ ] スマートフォンのカメラで縦向きに撮った写真を設定しても、横倒しにならない（Android 8.x の端末でも確認する）
- [ ] 画像あり: 表示された誘導先の編集画面で選んだ画像が丸く切り抜かれて表示される
- [ ] 画像なし: アプリの誘導先はそのアプリのアイコン、Web サイトの誘導先は地球のアイコンが表示される
- [ ] タイトル・「開く」ボタン・「長押しで退避（3秒）」が、昼・夜どちらの背景でも読める
- [ ] 「長押しで退避（3秒）」を 3 秒長押しするとホームへ移動する。途中で離すとリセットされる
- [ ] 戻るボタン / 戻るジェスチャーでホームへ移動する
- [ ] 誘導先のアプリをアンインストールすると「開く」が無効になり「アプリが見つかりません」と表示される
- [ ] スヌーズ用ゲートは最近のタスクに表示されない

### 11.9 スヌーズを止める

- [ ] 「開く」ボタンの下に「スヌーズを止める」が控えめに表示され、昼・夜どちらの背景でも読める
- [ ] 押すと「スヌーズを OFF にしますか？スヌーズ設定からいつでも ON に戻せます。」のダイアログが出る。「キャンセル」では何も変わらない
- [ ] 「OFF にする」を押すと、スヌーズ用ゲートが閉じて元の監視対象アプリに戻る（ホーム画面には移動しない）
- [ ] その後、どの監視対象アプリを開いても、間隔がたってもスヌーズ用ゲートは出ない（アプリ全体で OFF になる）
- [ ] ホームの状態表示が「スヌーズ：OFF」になり、スヌーズ設定画面のスイッチも OFF になっている。ON にすると、間隔・時間帯が元の設定のまま表示される
- [ ] 「スヌーズを止める」では、誘導先の最終訪問日は変わらず、ホームの「今日はゲート通過済み」も表示されない

### 11.10 アップデート後の引き継ぎ（v0.1.6 → v0.1.7）

- [ ] v0.1.6 で、誘導先 A（未訪問・スヌーズ ON・5分おき・8:00〜23:00）と誘導先 B（訪問済み・スヌーズ ON・1時間おき）を登録した状態から v0.1.7 に上書きアップデートすると、スヌーズ設定は「ON・5分おき・8:00〜23:00」（A の設定）になっている
- [ ] v0.1.6 でどの誘導先もスヌーズ OFF だった場合は、アップデート後のスヌーズ設定は OFF（ON にすると 30分おき・9:00〜22:00）
- [ ] 引き継ぎは最初の起動の 1 回だけ。アップデート後にスヌーズ設定を変更し、アプリを再起動しても変更が残っている
- [ ] 誘導先（タイトル・URL / アプリ・スケジュール・最終訪問日・スヌーズ用ゲートの画像）と監視対象アプリがすべて残っている
- [ ] （v0.1.3 以前から直接アップデートした場合）誘導先と監視対象アプリがすべて残っていて、スヌーズ設定は OFF
